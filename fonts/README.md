# Fonts

Be Vietnam (the original family, not Be Vietnam Pro), by Lam Bao, Tony Le and Viet-Anh Nguyen.
Source: https://github.com/bettergui/BeVietnam (ttf/, Version 5.000)
Licence: SIL Open Font License 1.1 (see OFL.txt)

Files here are the Regular (400), Medium (500) and Bold (700) TTFs converted to WOFF2
with fontTools. No glyphs were changed or removed. Bold is used only for "Welly." in the wordmark.

The serif (Times New Roman) is not hosted here. It is a Monotype font that needs a paid web
licence to self-host, so the site uses it from the visitor's device with metric-compatible fallbacks.
